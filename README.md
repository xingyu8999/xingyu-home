# 马星煜的个人主页

这是我的个人主页，也是一个长期维护的作品集。

我希望它不是一份堆满关键词的简历，而是一个能让别人快速了解我的地方：我在做什么、我擅长什么、我怎么思考问题，以及哪些内容可以继续交流。

目前网站主要围绕几个方向展开：

- 机器学习
- 前端设计
- 机器视觉
- 数学建模
- AI 开发
- 论文与研究记录
- 一些个人兴趣和交流入口

我更喜欢克制一点的表达。页面里不会放太多花哨的东西，重点还是放在内容、结构和真实可聊的部分。

## 关于我

我叫马星煜，是一名在读研究生。

我喜欢数学，也喜欢用公式、逻辑和代码去理解问题。  
技术方向上主要做前端开发、AI 开发、数学建模和机器视觉。  
平时也喜欢音乐、喝茶、盘串、公路车、摩托车和钓鱼。

我希望这个网站给人的感觉是：

低调，但不是空白。  
有技术含量，但不端着。  
有设计感，但不喧宾夺主。

## 网站内容

### 首页

首页主要展示我的个人介绍、能力方向和一些我认为重要的表达。

一句话概括：

> 用代码把想法落地。

### 项目展示

项目区目前按下面的顺序组织：

1. 机器学习
2. 前端设计
3. 机器视觉
4. 数学建模
5. AI 开发

后续这里会继续接入更多真实项目，包括 GitHub 仓库、在线 Demo、自己写的 HTML 页面，或者完整的项目介绍页。

我不太想把项目区做成简单的“卡片堆叠”，而是希望每个项目都能说明：

- 这个方向在解决什么问题
- 我用了什么方法
- 最后能产出什么东西
- 是否有代码、论文、页面或者实验结果可以查看

### 我的论文

论文区会放我参与发表或完成的研究内容。

目前分成两类：

- 重点展示论文
- 其他论文归档

重点论文会展示得更完整一些，其他论文则默认折叠，避免页面太长。

### 留言板

网站里做了一个留言板入口。

目前留言功能更偏展示和轻量交互，后续可以根据需要接入数据库、邮件通知或者后台审核。

## 技术栈

这个网站使用：

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Vitest
- Testing Library

主要目标不是炫技术栈，而是让代码结构清楚、页面好维护、后续方便继续加内容。

## 本地运行

安装依赖：

```bash
npm install
````

启动开发环境：

```bash
npm run dev
```

打开浏览器访问：

```bash
http://localhost:3000
```

## 测试与检查

运行代码检查：

```bash
npm run lint
```

运行测试：

```bash
npm run test
```

运行覆盖率测试：

```bash
npm run test:coverage
```

生产构建：

```bash
npm run build
```

如果只想一次性检查整体状态：

```bash
npm run check
```

## 目录结构

```bash
app/
  content.ts        # 页面主要内容数据
  globals.css       # 全局样式
  layout.tsx        # 页面布局
  page.tsx          # 首页主体

components/
  ThemeToggle.tsx   # 亮色 / 暗色主题切换

public/
  images/           # 图片资源

tests/
  # 页面、内容、交互和样式相关测试
```
